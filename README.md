# Oasis Detailing Supplies — website redesign

Redesign of **oasisdetailersource.com** for Oasis Detailing Supplies Inc, Orange, CA.
This is the main project in this repo.

## Structure

- `index.html` / `shop.html` / `styles.css` / `script.js` — the live site (static, no build step)
- `content/*.json` — site content (services, brands, products, reviews, hours, phones)
- `images/` — logo, social icons, and product/brand photos (`images/products/<Brand>/`)
- `pinstack/` — separate project: the Pinstack Design studio site

## Run

Open `index.html` in a browser, or serve the repo root with any static server.
Deploy: connect the repo to Netlify (or similar) with the publish directory set to the repo root.
