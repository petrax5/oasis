# Pinstack Design

A responsive, one-page local-business web design studio site inspired by the Pinstack direction discussed in chat.

## Run
Open `index.html` in a browser, or run `python3 -m http.server 8000` in this folder.

## Customize
- Replace the Pinstack name/logo with your final brand.
- Change `hello@pinstack.design` in `index.html`.
- Replace the three sample projects with your actual portfolio examples.
- Add real images/assets when ready.
- Update services/pricing as your offer develops.
